# DazzleDre//\DreDazzle

**Daz** is Dre's creative universe: experimental audiovisual toys, games and tools, made with AI collaborators under human direction. Repository: `DazzleDre-DreDazzle` (private). Planned address: https://dazzle.dredarkroom.com (not live yet).

The first chapter is **Mallard Protocol**, a psychedelic dark-techno journey that started life as a rhythm puzzle: a yellow rubber duck that turns out to be a cyborg, optical illusions, a hand-inked striped cat, mini games, a labyrinth, a starship and a robot at 6 minutes 66 seconds.

## Start here
- Humans: `labs/mallard/README.md`, then `labs/mallard/ROADMAP.md`.
- AI agents: `AGENTS.md`, then `docs/dazzledre/AI-PACK.md`.
- Try it: open `labs/mallard/index.html` in a browser (headphones help), or `docker compose up serve` and visit http://localhost:8080/mallard/.
- Check it: `cd tests && npm install && npx playwright install chromium && npm test`.

## Safety
Nothing flashes more than 3 times per second. The experience opens with a warning screen and offers Calm, Full and an opt-in Intense mode, with skip buttons in the games and the robot scene.

## Status
Working prototype. Not deployed. See `labs/mallard/DEVLOG.md` for what is verified and what is not.
